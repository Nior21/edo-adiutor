## Изменения
- **XML «Сохранить как…»**: в тонком/толстом клиенте — диалог 1С и **полный путь** в подсказке; в веб-клиенте без диалога — файл в «Загрузки» браузера (путь в настройках браузера).
- ПКМ по строке → **Сохранить XML как…** (несколько файлов — подпункты после загрузки карточки).
- Карточка: поля **одной колонкой** (без налезания).
- Завершённые/удалённые/проведённые строки **приглушены**; по умолчанию скрыты, чекбокс **«показывать все»** слева от версии UI в статусбаре.
