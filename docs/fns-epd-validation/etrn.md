# ЭТрН — правила валидации (черновик)

> Заполнение в процессе. Структура таблицы — образец для остальных типов.

## Легенда уровней

- **error** — нарушение формата/обязательности; документ с высокой вероятностью не примет ГИС/оператор
- **warn** — спорно или зависит от контекста (роль участника, сценарий перевозки)
- **external** — нужна проверка вне ИБ (адрес ФИАС, классификатор, реестр ТС и т.д.)
